##  Quick Start

```bash
# clone
git clone https://github.com/Abhitkumar89/AbhitKumar_Portfolio.git
cd AbhitKumar_Portfolio

# install & run
npm install
npm run dev          #  http://localhost:5173
```

<details>
<summary><b> More commands</b></summary>

<br>

```bash
npm run build        #  production build → dist/
npm run preview      #  preview the production build
npm run lint         #  run eslint
```

</details>

##  Make It Yours

<details open>
<summary><b> Everything lives in one file</b></summary>

<br>

```
src/data/content.js   ←  edit name, roles, projects, skills, education, experience, links
```

No need to touch the components — just update the data and the whole site follows.

</details>

<details>
<summary><b> Project structure</b></summary>

<br>

```
Portfolio/
├─  public/            # resume.pdf, favicon
├─  src/
│  ├─  components/      # Navbar, Timeline, cursor, cards...
│  ├─  sections/        # Hero, About, Education, Skills...
│  ├─  data/content.js  # ← single source of truth
│  ├─  lib/motion.js    # shared animation variants
│  ├─  App.jsx
│  └─  index.css
├─  index.html
└─  tailwind.config.js
```

</details>

<details>
<summary><b> Contact form (EmailJS)</b></summary>

<br>

The form runs in **demo mode** until you add keys:

1. Create a free account at [emailjs.com](https://www.emailjs.com/)
2. Make a service + template (`user_name`, `user_email`, `subject`, `message`)
3. Paste `serviceId`, `templateId`, `publicKey` into `emailjsConfig` in `src/data/content.js`

</details>
